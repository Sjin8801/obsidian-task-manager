# ADR 0001 — 기존 TaskNotes 형식을 보존하는 작은 어댑터

상태: 초기 읽기·미리보기 구현에 채택. 운영 쓰기 계약은 추가 검증 필요.  
날짜: 2026-09-14.  
갱신: 2026-09-29. 결정(작은 어댑터, mdbase 미채택)은 유지합니다. 이 결정이 언급한 재현용 비교 스크립트(`spike:mdbase`)와 mdbase 실험 의존성, API 경계는 로컬 볼트 전환 후 저장소에서 제거했습니다. 비교에 쓴 스크립트와 실행 결과도 저장소에 두지 않습니다.

## 판단

현재 배포 패키지의 mdbase를 작업 파일 writer로 채택하지 않고, 기존 필드와 원문을 보존하는 작은 어댑터를 구현한다. 인증·외부 접속은 별도 API 경계에서 처리한다.

## 근거

공개 npm에서 조회·설치한 `@callumalpass/mdbase@0.2.2`로 합성 작업 파일을 읽고 상태를 변경했다.

- 한국어 키 읽기·변경: 성공.
- 우선순위 원문 값과 본문: 유지.
- 대상 외 원문 바이트 및 주석: 유지되지 않음.
- 명시적인 null 필드: 기본 설정에서 삭제됨.
- 설치 패키지의 공개 update 타입: path/fields/body만 있고 if_revision 없음.
- 별도 컬렉션 설정이 없는 폴더: missing_config 응답.

null 보존은 설정으로 개선할 여지가 있지만 주석·원문 보존과 요청 단위 revision 계약은 별도 보완이 필요하다. 그 보완 범위를 고려하면 필요한 좁은 계약을 직접 처리하는 편이 초기 의존성이 작다.

[GitHub main 문서](https://github.com/callumalpass/mdbase)는 0.3 계열과 if_revision을 설명한다. 이번 설치본과 다르므로 위 한계를 main 또는 mdbase Connect 전체에 일반화하지 않는다. Connect나 GitHub main의 실행·모바일 인증 연동은 시험하지 않았다. 문서에서 제공하는 가능성과 실제 시험한 배포본을 구분한다.

## 결과

- 런타임 파일 파서는 yaml이며 원문 값을 정규화해서 저장하지 않는다.
- mdbase는 재현용 실험 의존성에만 둔다. 실제 앱 런타임에 포함하지 않는다.
- 비교 스크립트는 `.local/`의 새 합성 폴더에만 쓰고 운영 보관함에 접근하지 않는다.
- 저장·충돌·휴지통·인증을 직접 구현하고 검증할 책임이 남는다.
- 향후 안정된 패키지가 계약을 충족하면 어댑터 경계 뒤에서 다시 비교할 수 있다.
